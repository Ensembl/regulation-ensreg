# ensreg
`ensreg` is a small script-like utility for use by [Ensembl Regulation](https://regulation.ensembl.org/). It is used at the final stage to produce our genomic regulatory annotation for ten species.

It is unlikely to be more generally useful at this stage. The primary reason for this package's availability is to document our annotation approach.
